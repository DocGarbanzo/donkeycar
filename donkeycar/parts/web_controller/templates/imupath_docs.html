📊 IMU Path Visualizer - User Guide

Overview

The IMU Path Visualizer helps you analyze your car's recorded driving sessions. It displays your driving path, detects laps automatically, segments the course into sections, and ranks your performance in each segment.

Basic Controls

Play/Pause Button
Start or stop automatic playback through your recorded path.
Time Slider
Drag to navigate to any point in your recording. You can also use keyboard arrow keys (← →) for frame-by-frame navigation.
Laps Selector
Choose how many laps to use for computing the mean reference course. The mean course is shown in cyan and represents the average path across the selected number of laps.
Segments Selector
Choose the algorithm for dividing the course into segments:
  • Threshold: Segments based on curvature thresholds
  • Extrema: Segments at curvature peaks/valleys
  • Gradient: Segments where curvature changes rapidly
  • Hybrid: Combines multiple methods (recommended)
Path/Mean Checkboxes
Toggle visibility of the driven path (your actual recording) and mean course (reference line).

Segment Performance Analysis

What are Segments?

Segments are geometric sections of your course (straights, turns, chicanes). The visualizer automatically divides your course into segments based on curvature analysis.

How Performance Ranking Works

For each segment, the visualizer compares how you drove it across different laps. It ranks each instance from 0% (worst) to 100% (best) based on the selected field and aggregation method.

Example: If you drove segment 3 in three laps with times of 2.1s, 1.8s, and 2.0s, the rankings would be:
Lap 1: 0% (slowest), Lap 2: 100% (fastest), Lap 3: 50% (middle)

Advanced: Custom Segment Statistics

When viewing Tub data (recorded driving sessions), you can analyze segment performance using any numeric field from your recordings.

Field Selector
Choose which data field to analyze:
  • time - Time spent in segment (built-in)
  • distance - Distance traveled (built-in)
  • car/speed - Vehicle speed data
  • imu/gyr - Gyroscope data (smoothness)
  • imu/acl - Accelerometer data
  • ... any numeric field from your tub
Method Selector
Choose how to aggregate the field values within each segment:
  • delta - Last minus first (for time, distance)
  • mean_abs - Average of absolute values
  • sum_abs - Sum of absolute values
  • max - Maximum value in segment
  • min - Minimum value in segment
  • norm - Euclidean magnitude (for vectors)
Dimension Selector
For vector fields (like IMU data), choose which component to analyze:
  • X - First component
  • Y - Second component
  • Z - Third component
  • Magnitude - Combined length of vector
💡 Tip: Use imu/gyr Z-axis with sum_abs to measure driving smoothness. Lower values = smoother steering.

Understanding the Display

Current Position Panel

Shows real-time information about the current position on the path:

  • Date/Time: Recording timestamp
  • Index: Data point number
  • Lap: Current lap number (0-based)
  • Segment: Current segment ID
  • Speed: Vehicle speed in m/s
  • IMU Yaw: Heading angle from IMU
  • X/Y: Position coordinates in meters
  • Total Dist: Cumulative distance traveled
  • Lap Dist: Distance within current lap
  • Seg Rank: Performance ranking (0-100%)

Path Visualization

  • Color-coded points: Each point shows segment ranking by color (red = worst, green = best)
  • Segment boundaries: White lines perpendicular to the course
  • Mean course: Cyan line showing average path
  • Current position marker: Red circle with white border

Training with Segment Performance

After analyzing your data, you can use segment-based training to create a model that learns from the best-driven instance of each segment, rather than just the best complete lap.

  1. Record multiple laps with varied performance
  2. Run: donkey segment --tub ./data/
  3. Enable in config: SEGMENT_PCT_MODE = True
  4. Train: python manage.py train --tub ./data/

The model will learn a "synthetic perfect lap" combining the best driving from each segment across all your laps.

⚠️ Note: Segment-based training requires segmentation data to be computed first using donkey segment command.

Keyboard Shortcuts

  • ← (Left Arrow): Go to previous frame
  • → (Right Arrow): Go to next frame
  • Space: Play/Pause (when plot is focused)

Configuration

💡 Advanced: You can configure which fields are available for segment analysis by editing FIELD_AGGREGATIONS in your config.py file. Pass --config /path/to/config.py when starting the visualizer.
